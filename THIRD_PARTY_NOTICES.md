# Third-party frontend dependencies

The following runtime assets are bundled locally, unmodified:

- HTMX 2.0.4: `static/vendor/htmx.min.js`, Zero-Clause BSD; https://github.com/bigskysoftware/htmx
- Alpine.js 3.14.9: `static/vendor/alpine.min.js`, MIT; https://github.com/alpinejs/alpine
- Tailwind CSS 3.4.17: generated utility stylesheet, MIT; https://github.com/tailwindlabs/tailwindcss

License copies are stored beside the bundled scripts. Python dependency license metadata is distributed with each installed package.
